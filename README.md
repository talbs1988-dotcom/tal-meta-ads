# ערכת הפרסום הממומן — טל בשור

**מנהל קמפיינים שמעלה קמפיין מטא מקצה לקצה.** אומרים לו "אני רוצה להעלות קמפיין על X", והוא עושה את השאר. הוא עוצר לאישור שלך בכל נקודה רגישה, ומדליק רק אחרי שכתבת "תדליק".

## התקנה

```bash
claude plugin marketplace add talbs1988-dotcom/tal-meta-ads
claude plugin install tal-meta-ads@tal-meta-ads
```

## לפני ההתחלה

- **חשבון מודעות במטא:** מחובר דרך הקונקטור של Meta, בהגדרות הקונקטורים של claude.ai. Claude Code צריך להיות מחובר לאותו חשבון claude.ai. ⚠️ החיבור נפתח לחשבונות בהדרגה. אם עוד לא נפתח אצלך, המנהל יגיד את זה.
- **דף פייסבוק** שמחובר לחשבון המודעות. אינסטגרם מחובר הוא רשות. בלעדיו המודעות ירוצו רק בפייסבוק.
- **הסקיל `landing-page-system`:** בשביל תת-הסוכן של דף הנחיתה. מתקינים אותו מספריית הסקילים של הסדנה (github.com/talbs1988-dotcom/claude-skills-shareable) עם הפקודה:
  `curl -fsSL https://raw.githubusercontent.com/talbs1988-dotcom/claude-skills-shareable/main/install.sh | bash -s landing-page-system`
- **node, python3 ו-Pillow:** בשביל יצירת התמונות. את Pillow המנהל מתקין לבד אם הוא חסר.
- **מפתח OpenAI עם חיוב פעיל:** בשביל יצירת התמונות. נכנס לקובץ `.env` בתיקיית העבודה: `OPENAI_API_KEY=sk-...`. לא מדביקים אותו בצ'אט.

## איך זה עובד

הסקיל `campaign-manager` הוא המנהל, והוא היחיד שמדבר איתך. מתחתיו עובדים 7 תתי-סוכנים (בתיקייה `agents/`). כל אחד מהם עושה שלב אחד עם הסקיל של השלב:

```
1 דף נחיתה          campaign-landing    landing-page-system
2 תשתית             campaign-infra      שלבי הקמה 1–2
3 רעיון וזווית      campaign-angle      meta-campaign-builder · meta-report · ad-copywriter
4 קמפיין והחרגות    campaign-build א'   שלב הקמה 3
5 קריאייטיב         campaign-creative   ad-creative
6 קופי              campaign-copy       ad-copywriter · שלב הקמה 4א
7 העלאה וצ'קליסט    campaign-build ב'   שלבי הקמה 4ב ו-5
8 הדלקה             המנהל, רק אחרי "תדליק"
  מדידה             campaign-report     meta-report
```

## הסקילים

| סקיל                        | מה הוא עושה                                                                                    |
| --------------------------- | ---------------------------------------------------------------------------------------------- |
| **`campaign-manager`**      | המנהל. מריץ את כל השלבים, שואל רק מה שחסר, ועוצר לאישורים.                                    |
| **`ad-copywriter`**         | כותב את המודעה בעברית: שלוש השורות שעוצרות גלילה, הגוף והכותרת.                                |
| **`ad-creative`**           | מייצר את התמונה. GPT-IMAGE-2 לתמונת הבסיס, ושכבת טקסט עברית ב-HTML מעל.                        |
| **`meta-campaign-builder`** | בונה את הקמפיין בחשבון: קמפיין, סדרות מודעות, מודעות. כולל את שלב הלמידה ואת המלכודות הידועות. |
| **`meta-report`**           | מודד מה רץ: מי מביא, מי שורף, ומה להגדיל או לעצור.                                             |

## שני דברים שחשוב לדעת

**שום דבר לא עולה לאוויר בלי "תדליק".** הכל נוצר כטיוטה בחשבון, ולא יוצא שקל. לפני כל יצירה המנהל מראה לך טבלה ומחכה ל"אשר". הקמפיין עולה לאוויר רק אחרי שכתבת "תדליק".

**קמפיין הוא החלק האחרון, לא הראשון.** בלי פיקסל בדף, בלי טופס או כפתור רכישה, ובלי מקום שהליד מגיע אליו, הקמפיין מביא תנועה שנעלמת. לכן המנהל מתחיל מדף הנחיתה ומהתשתית.
