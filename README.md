# ערכת הפרסום הממומן — טל בשור

ארבעה סקילים שעובדים ברצף אחד: **מרעיון לקמפיין בחשבון.**

## התקנה

```bash
claude plugin marketplace add talbs1988-dotcom/tal-meta-ads
claude plugin install tal-meta-ads@tal-meta-ads
```

## מה יש בפנים

| סקיל                        | מה הוא עושה                                                                                    |
| --------------------------- | ---------------------------------------------------------------------------------------------- |
| **`ad-copywriter`**         | כותב את המודעה בעברית — שלוש השורות שעוצרות גלילה, הגוף והכותרת. 19 סוגי מודעה, 7 דפוסי פתיחה. |
| **`ad-creative`**           | מייצר את התמונה — GPT-IMAGE-2 לתמונת הבסיס, שכבת טקסט עברית ב-HTML מעל. כולל סקריפט ותבנית.    |
| **`meta-campaign-builder`** | בונה את הקמפיין בחשבון — קמפיין ← קבוצת מודעות ← מודעה. **עוצר לאישור, ויוצר מושהה.**          |
| **`meta-report`**           | מודד מה רץ — מי מביא, מי שורף, ומה להגדיל או לעצור.                                            |

## הרצף

```
ads_copywriter  →  ad-creative  →  meta-campaign-builder  →  meta-report
   הטקסט            התמונה            הקמפיין                 המדידה
```

## מה שצריך שיהיה מחובר

- **חשבון מודעות במטא** — דרך הקונקטור של Meta. ⚠️ החיבור בהשקה הדרגתית; אם הוא עוד לא נפתח לחשבון, הסקילים יגידו את זה במקום ליפול.
- **מפתח OpenAI** — רק ל-`ad-creative`. בקובץ `.env`: `OPENAI_API_KEY=sk-...`

## שני דברים שחשוב לדעת

**הקמפיין נוצר תמיד מושהה.** `meta-campaign-builder` לא מפעיל כלום ולא מוציא שקל. הוא מציג טבלה של מה עומד להיווצר, מחכה ל"אשר", יוצר — וההפעלה נשארת החלטה שלך במנהל המודעות.

**קמפיין הוא החלק האחרון, לא הראשון.** בלי פיקסל בדף היעד, בלי טופס, ובלי מקום שהליד נוחת אליו — הקמפיין מביא תנועה שנעלמת. `meta-campaign-builder` בודק את זה לפני הכל ועוצר אם משהו חסר.
