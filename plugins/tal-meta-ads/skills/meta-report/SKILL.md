# דוח ביצועים למטא — מה עובד, מה שורף

מוציא תמונת מצב על הקמפיינים שרצים, בעברית, עם המלצות שאפשר לפעול לפיהן.

## שלב 1 — לוודא שאפשר לקרוא

```
ads_get_ad_accounts
```

לבדוק שני שדות בתשובה:

- `is_queryable: true` — אם `false`, להציג את `not_queryable_reason` ולעצור
- `is_ads_mcp_enabled` — אם `false`, החיבור עדיין לא נפתח לחשבון (השקה הדרגתית של מטא, לא תקלה אצל המשתמש)

## שלב 2 — למשוך את הנתונים

⚠️ **שמות הכלים המדויקים.** אלה השמות האמיתיים — לא לנחש ולא להמציא:

```
ads_get_ad_entities             ← הכלי המרכזי. קמפיינים/קבוצות/מודעות + מדדים
ads_entity_schedule_report      ← דוחות כבדים (אסינכרוני)
ads_entity_get_report           ← למשוך את התוצאה של הקודם
ads_insights_performance_trend  ← מגמות לאורך זמן
ads_insights_industry_benchmark ← השוואה לענף
```

הקריאה הבסיסית:

```
ads_get_ad_entities(
  ad_account_id = <ID>,
  level = "campaign",
  date_preset = "last_7d",
  fields = ["id","name","objective","status","amount_spent","impressions",
            "clicks","ctr","cpc","results","cost_per_result","lead",
            "cost_per_lead","reach","frequency"],
  sort = "amount_spent_descending"
)
```

**חובה `date_preset` או `time_range`.** בלעדיהם חוזרים רק מאפיינים, בלי שום מדד — וזו התקלה הכי נפוצה כאן.

**אם שדה נדחה:** השגיאה מחזירה את הרשימה המלאה של השדות הנתמכים באותה רמה. לקחת משם, לא לנחש. (`spend` למשל אינו חוקי — השם הוא `amount_spent`. `actions` אינו חוקי ברמת קמפיין.)

## שלב 3 — לקרוא את המספרים

| מדד           | מה הוא אומר            | מתי לדאוג                          |
| ------------- | ---------------------- | ---------------------------------- |
| **עלות לליד** | המדד היחיד שבאמת חשוב  | כשהוא עולה שבוע אחר שבוע           |
| **CTR**       | האם הקריאייטיב עוצר    | מתחת ל-1.5% — הקריאייטיב חלש       |
| **תדירות**    | כמה פעמים אותו אדם ראה | **מעל 3 — הקהל נשחק**              |
| **CPC**       | עלות לקליק             | קופץ בלי שהשתנה כלום = התחרות עלתה |

**התדירות היא הסימן המוקדם.** היא מטפסת לפני שעלות הליד עולה. תדירות 3+ אומרת: להחליף קריאייטיב, לא להעלות תקציב.

## שלב 4 — הדוח

בעברית, מספרים משמאל לימין:

```
📊 שבוע ‹תאריכים›

הוצאה     │ X ₪
לידים     │ Y
עלות לליד │ Z ₪   (שבוע שעבר: W ₪)

✅ הכי טוב
   ‹קמפיין› — ‹עלות לליד›, CTR ‹%›

⚠️ הכי גרוע
   ‹קמפיין› — ‹עלות לליד›, תדירות ‹X›

מה עושים
1. ‹פעולה קונקרטית עם מספר›
2. ‹פעולה›
3. ‹פעולה›
```

**המלצה טובה היא פעולה עם מספר.** לא "לשפר את הקריאייטיב" — אלא "להחליף קריאייטיב בקמפיין X, התדירות שלו 3.4 והוא עלה מ-22 ל-38 ₪ לליד".

## מה שהדוח לא רואה — ולומר את זה

הדוח מודד מה קרה **עד** שהליד נכנס. אם עלות הליד תקינה אבל אף אחד לא סוגר — הבעיה **אחרי** הקמפיין: אף אחד לא חוזר ללידים, או שהם נופלים בין הכיסאות.

כששואלים "למה אין מכירות למרות שיש לידים" — לא לחפש את התשובה במטא. היא לא שם.

## מלכודות

| מה קורה                           | למה                  | מה עושים                        |
| --------------------------------- | -------------------- | ------------------------------- |
| חוזרים שמות בלי מספרים            | חסר `date_preset`    | להוסיף טווח תאריכים             |
| `Unsupported field(s)`            | שם שדה לא חוקי       | לקחת מרשימת השדות שבשגיאה       |
| `is_queryable: false`             | החשבון חסום לשאילתות | להציג את `not_queryable_reason` |
| מספרים לא מסתדרים עם מנהל המודעות | חלון ייחוס שונה      | לציין את הטווח בדוח             |
