# קריאייטיב למודעות — התמונה שעוצרת את הגלילה

הקופי משכנע. **התמונה היא מה שגורם לאנשים לעצור כדי לקרוא אותו.**

הסקיל הזה מייצר את התמונה ומלביש עליה טקסט בעברית.

## איך זה עובד — שני שלבים

```
1. תמונת בסיס   →  GPT-IMAGE-2 מפרומפט מפורט
2. שכבת טקסט    →  HTML מעל התמונה → PNG סופי
```

**למה שני שלבים ולא אחד:** מודלים של תמונות כותבים עברית גרוע — אותיות הפוכות, מילים שבורות. הפתרון: התמונה נוצרת **בלי טקסט**, והטקסט מולבש אחר כך ב-HTML, נקי ומדויק.

## הכנה — פעם אחת

צריך מפתח של OpenAI. בקובץ `.env` בתיקיית העבודה:

```
OPENAI_API_KEY=sk-...
```

**עלות:** באיכות `low` — כ-0.006$ לתמונה. עשרים וריאציות עולות פחות משקל. אין סיבה לחסוך בניסיונות.

## שלב 1 — לשאול לפני שמייצרים

1. **מה מפרסמים?**
2. **מה הרגש שהתמונה צריכה לעורר?** (הקלה · דחיפות · סקרנות · אמון)
3. **צבעי המותג?** (שניים — ראשי ומשני)
4. **פורמט?** ריבוע 1080×1080 לפיד · אנכי 1080×1350 לפיד מורחב · 1080×1920 לסטורי וריל

אם המשתמש לא יודע מה הוא רוצה — **להציע שלושה כיוונים שונים ולתת לו לבחור**, לא לשאול עוד שאלות.

## שלב 2 — לכתוב את הפרומפט

פרומפט לתמונת מודעה הוא לא "תמונה של X". הוא בנוי מחמישה חלקים:

| חלק       | מה כותבים          | דוגמה                                                    |
| --------- | ------------------ | -------------------------------------------------------- |
| פורמט     | גודל ויחס          | `Square 1024x1024 advertisement`                         |
| גיבור     | מה תופס 50% מהקנבס | `hyper-realistic 3D render of a glowing terminal window` |
| סגנון     | איך זה נראה        | `premium, studio lighting, soft reflections`             |
| צבעים     | פלטה מדויקת        | `deep navy background, warm gold accents`                |
| **שלילה** | מה אסור            | `no text, no letters, no words, no watermarks`           |

⛔ **`no text` הוא חובה בכל פרומפט.** בלעדיו המודל ינסה לכתוב, ובעברית זה תמיד יוצא שבור.

**מה עובד בקריאייטיב למודעה:**

- **אובייקט אחד גדול במרכז** מנצח סצנה עמוסה. הפיד קטן — פרטים נעלמים.
- **ניגודיות גבוהה.** התמונה מתחרה מול פיד לבן; משהו כהה או רווי בולט.
- **תחושת תנועה או התקדמות** — משהו שקורה — עוצר יותר מתמונה סטטית.
- **בלי אנשים גנריים מבנק תמונות.** הם קוראים כפרסומת ומורידים אמון.

## שלב 3 — לייצר

```bash
node scripts/generate-images.mjs prompts.json ./out
```

`prompts.json` — מערך: `[{ "id": "v1-terminal", "prompt": "..." }, ...]`

**לייצר 4–6 וריאציות בסבב הראשון**, לא אחת. הן עולות אגורות, וההבדל בין הראשונה לרביעית הוא בדרך כלל גדול.

## שלב 4 — להלביש את הטקסט

לקחת את `templates/overlay.html`, למלא את הטקסט והצבעים, ולרנדר ל-PNG.

**כללי הטקסט על התמונה:**

- **שלוש מילים עד שבע.** לא משפט. הקופי המלא הולך בגוף המודעה, לא על התמונה.
- **פונט Rubik** — נקי, קריא בעברית, עובד קטן.
- **RTL תמיד** — `dir="rtl"`.
- **מקסימום שתי שכבות טקסט**: אמירה אחת + קריאה לפעולה. שלוש = עומס.
- **רקע חצי-שקוף מתחת לטקסט** אם התמונה עמוסה. טקסט על רעש לא נקרא.
- **לבדוק בקטן.** להקטין ל-30% ולהסתכל — ככה זה ייראה בפיד.

## שלב 5 — סבבים

**קריאייטיב טוב הוא לא הראשון.** לרוב זה הרביעי או השמיני.

אחרי כל סבב לשאול: **מה עצר אותי כאן, ומה לא?** ולשנות דבר אחד בכל פעם — צבע, או גיבור, או זווית. לא הכל ביחד, אחרת אי אפשר לדעת מה עבד.

לשמור כל סבב בשם ברור: `v1-`, `v2-`, `regen-color`, `regen-hero`.

## מלכודות

| מה קורה            | למה              | מה עושים                           |
| ------------------ | ---------------- | ---------------------------------- |
| עברית שבורה בתמונה | המודל ניסה לכתוב | `no text` בפרומפט + טקסט ב-overlay |
| התמונה נראית גנרית | הפרומפט קצר מדי  | להוסיף חומר, תאורה, זווית          |
| לא רואים כלום בפיד | יותר מדי פרטים   | אובייקט אחד גדול                   |
| הטקסט לא נקרא      | אין ניגודיות     | רקע חצי-שקוף מתחת                  |
| חשבון OpenAI נשרף  | איכות `high`     | `low` בלבד — ההבדל לא נראה בפיד    |

## הקבצים

- `scripts/generate-images.mjs` — מייצר את התמונות
- `templates/overlay.html` — תבנית שכבת הטקסט
